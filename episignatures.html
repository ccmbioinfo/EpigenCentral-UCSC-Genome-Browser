EpigenCentral DNA Methylation Episignatures

This track displays CpG probes from 20 published DNA methylation episignatures curated by EpigenCentral. Each probe represents a differentially methylated CpG associated with one or more genetic disorders. When a CpG is shared among multiple episignatures, the displayed color and mouse-over information are determined by the episignature showing the largest absolute methylation change (largest absolute deltaBeta value).

Color Coding

Delta beta values are calculated as mean methylation in cases minus mean methylation in controls (deltaBeta = Cases − Controls). Positive deltaBeta values indicate increased methylation in cases (Gain), whereas negative deltaBeta values indicate decreased methylation in cases (Loss).
  • Orange: Gain of methylation (positive deltaBeta)
  • Blue: Loss of methylation (negative deltaBeta)

Track Layout

  • Dense view: Colored bars only.
  • Pack view: Colored bars with CpG probe IDs.
  • Full view: Colored bars with CpG probe IDs.

Mouse-over Information

Hovering over a CpG displays:

  • The episignature driving the displayed color.
  • The methylation direction (Gain or Loss).
  • The corresponding deltaBeta value.

Example: 

NSD1 | Loss | -0.346

Item Details Page

Clicking on a CpG probe opens a detailed comparison table showing all episignatures that contain that CpG.

The table includes:

  • Gene
  • Associated disorder
  • OMIM identifier
  • Methylation direction
  • deltaBeta
  • Adjusted p-value
  • Multiple-testing correction method

Filters

  • Episignature Filter: Select one or more episignatures to display CpGs that overlap the chosen signatures.
  • Number of Overlapping Episignatures: Restrict the display to CpGs present in a specified number of episignatures.

Interpretation

A CpG observed in multiple episignatures may represent:

  • Shared biological pathways.
  • Common chromatin regulatory mechanisms.
  • Convergent neurodevelopmental disease processes.
  • Overlapping epigenetic signatures between syndromes.

Users interested in specific disease mechanisms can use the episignature filters to identify shared CpGs between disorders such as autism-related episignatures, overgrowth syndromes, and neurodevelopmental disorders.

Probe Annotation

All CpG probes displayed in this track were mapped using Illumina Infinium MethylationEPIC v2 (EPIC v2) array annotations. Only probes with valid hg38 genomic coordinates and present in the EPIC v2 annotation set were included in the final track.
